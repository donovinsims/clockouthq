# Ten-minute weekly founder review
Proposed template from A02, not an automation.

1. What money, customer conversations and completed work actually occurred?
2. Which single constraint is limiting the next result?
3. What decision or assumption changed based on evidence?
4. What is the next most valuable action, and what must stop?
5. Which canonical docs and changelog entries need updating?

Record the date, source references, one primary next action, owner and due date. Keep private client/financial details outside this reusable folder. Unknown counts remain unknown; the Oct 29 acquisition confirmation is historical rather than an evergreen zero.

## Changelog entry
Date / event date / change / reason / source / affected canonical files / status / next step.
