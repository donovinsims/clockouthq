## Historical snapshots
Source extracts preserve selected owner statements, attributed assistant reports and historical local files. They may contain old “current” claims or obsolete instructions. Their warning headers and source IDs distinguish them from the living source of truth.

The SHA256SUMS file at the docs root allows a future user to check that packaged files match this baseline. It does not prove the business claims inside the files.
