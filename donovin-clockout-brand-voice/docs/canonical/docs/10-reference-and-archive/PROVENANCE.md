# Provenance and confidence
Baseline date: 2026-10-29, America/Chicago.

## Status vocabulary
- **CONFIRMED:** Direct owner statement or explicit current task establishes the intent/fact. It can still be self-reported rather than independently substantiated.
- **REPORTED:** A document or assistant records a result; current execution did not independently repeat it.
- **OBSERVED:** This run directly inspected a file or result. Observing a file does not validate every claim inside it.
- **PROPOSED:** Recommendation or template, awaiting adoption in its specific use.
- **HYPOTHESIS:** A testable belief about customers or outcomes.
- **UNKNOWN:** Evidence absent, incomplete, contradictory or too stale.
- **SUPERSEDED:** Valid historical context displaced by newer owner intent or evidence.
- **HOLD:** Do not proceed on the affected assumption until resolved.

Confidence is about support for a specific claim, not confidence in a person. High confidence in an owner's approval does not prove an edit was saved.

## Authority by question
Intent: latest explicit owner decision.
Configuration: latest direct saved/reloaded observation of the correct record.
Publication: actual deployment/profile publication evidence.
Outcome: measured results with date/denominator.
Historical wording: original contemporaneous source.

A later summary does not erase a conflicting original. Record the conflict and get the missing evidence.

## Claim record
ID; claim; status; source ID and locator; event date; retrieval date; author/source type; confidence and basis; limitation; canonical file; next verification.

Example:
CASH01 · $500 available by Nov 10 · CONFIRMED current owner mission · current request/S01 · Oct 29 · high confidence in intent · actual receipts unknown · CURRENT_STATE.

OFFER01 · $500 / $250 + $250 · REPORTED working offer · S01 assistant recap · Oct 29 · medium confidence in exact original adoption · price revised on 2026-10-31; quoted terms still need scoped agreement · website-offer.
