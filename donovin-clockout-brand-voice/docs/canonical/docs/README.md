## How to interpret this package
**CONFIRMED** means supported by a direct owner statement or explicit current task instruction. **REPORTED** means a source records it but this baseline did not independently repeat the observation. **PROPOSED** means an actionable recommendation, not adopted policy. **HYPOTHESIS** needs market evidence. **UNKNOWN** lacks sufficient evidence. **SUPERSEDED** remains historical only.

Important distinctions are preserved: current owner intent versus observed configuration; saved versus published; contract value versus collected funds; mentor examples versus Clockout results.

See [provenance rules](10-reference-and-archive/PROVENANCE.md), [coverage and limitations](10-reference-and-archive/COVERAGE_AND_GAPS.md), and [contradictions](09-execution-and-decisions/contradictions.md). This package comprehensively organizes recovered evidence; it cannot certify that every September–October event or missing attachment has been recovered.
