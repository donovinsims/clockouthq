## Original text

The most underrated thing you can do with Claude Code right now:

Remotion Recaps

It's been super useful asking Claude to turn its own output into a 2-minute video.

I've been doing this for plans, audits, research, call breakdowns, etc. Works especially well if you hate reading long text output.

An exercise you can do right now:

Open Claude Code. Point it at any doc, transcript, article, or link. Then paste this:

"Read [link or file]. Turn it into a 90-second to 2-minute Remotion video that explains the core ideas to me, so I don't have to read the whole thing.

- Write the script first: 6-10 scenes, 2-5 short lines each.
- One idea per scene: big headline, a few labeled cards, a progress bar so I know where we are.
- Add a voiceover and time each scene to its audio.
- Render the video as a shareable Claude artifact so I can share it with my team if needed."

Just did this with a 20+ page build plan doc for a project I'm working on. 64 sections became 9 scenes and 2 minutes of video.

The default voice it uses is Mac voice which sounds super robotic. If you want a better voice ask Claude to use Treg to find a higher quality voice (will cost ~$0.05 or less).

This is really useful for making Claude SHOW you its work in a visual format.
