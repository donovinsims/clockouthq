## Original text

A simple framework I use to delegate tasks to AI agents is Why/Done/Access.

On your to do list app of choice try including these 3 lines in the description of each task:

Why:
Done:
Access:

Here's a few examples:

Send invoice to new client

-Why: get paid before month end
-Done: invoice sent, due date in the CRM
-Access: Stripe, signed proposal in Drive

Lock recording date with podcast guest

-Why: episode needs to ship this month
-Done: date on calendar, recording link sent
-Access: Gmail thread, calendar

This allows me to point any agent at my to do list and ask it to execute, and it has all the context needed without getting stuck. 

This is the prompt I give my agent every morning:

"Pull every task due today. Analyze the Why/Done/Access fields to get the context you need to fully complete each task. For any tasks that you’re unable to complete, do as much of the work as you possibly can then tee up the remaining work for me or my assistant to finish off.”

Make sure each of your descriptions pass this test: could someone who has never met you finish the task from it alone?

Yes, it's a pain for tasks like "book haircut."

But taking 30 seconds to add context is the boring work required to empower agents to fully execute tasks.
