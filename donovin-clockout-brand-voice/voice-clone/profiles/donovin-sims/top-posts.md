If code is unavailable, use these abstractions rather than full corpus exposure:
1. Concrete task → labeled inputs → numbered steps → expected output → check.
2. Operational problem → owner/handoff → smallest useful change → measurement.
3. Supported observation → mechanism → tradeoff → useful conclusion.
4. Article: problem → sections that build a method → worked example → limitations.

The active workflow does not need to load every historical top post. Curated historical examples may include evaluation holdouts; normal retrieval excludes those. Do not use the historical curated file to condition a blinded test.
