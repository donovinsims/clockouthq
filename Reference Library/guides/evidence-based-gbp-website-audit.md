# Audit a lead’s GBP and website with evidence

**Topics** · google-business-profile, local-seo, website-audit

## When to use it

Use for a read-only review when a potential lead asks what could be improved across their profile and website. Apply the guide to the current brief and use the evidence and access available for that task.

## Inputs

The lead’s profile and site URLs, confirmed business details if shared, review scope, and any authorized exports. Competitor URLs are optional.

## Steps

1. Choose the fields and pages in scope. Cover visible categories, attributes, services, photos, core service pages, and the contact path where relevant.
2. Record each observation with a date and source URL or export. Give the observed value and the expected value only when you have a reliable basis.
3. Classify findings as verified issue, opportunity, or unknown. For each finding, assign a next step and the evidence or owner input it needs.
4. Group the findings into items that affect customer access or accuracy, then improvements with weaker or indirect evidence.

## Decision rules

Use competitor profiles as examples of presentation or coverage. A missing competitor attribute is a question to validate with the lead. Treat rankings and effects inferred by the source’s prompts as unverified. A lead review can produce findings and a brief using public or authorized material. Apply changes within the project’s authorized scope.

## Expected output

A findings table with field or page, observed evidence, classification, priority, and next step.

## Verification

Open or locate the evidence behind each verified finding. Check that unknowns remain labeled and that proposed actions fit the lead’s business.

## Example

If a profile lists a service the website omits, record the discrepancy and confirm the actual offering before recommending a site addition or a profile correction.
