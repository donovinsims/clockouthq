# Review the mobile homepage’s first screen

**Topics** · website-conversion, mobile, local-business

## When to use it

Use for a quick lead-site review or to prioritize the mobile layout of a future website. Focus on what the first screen communicates. Apply the guide to the current brief and use the evidence and access available for that task.

## Inputs

A live URL, screenshot, or preview, one narrow mobile viewport, the lead’s confirmed core service and area, approved proof, and the primary inquiry route.

## Steps

1. Capture the first screen at a recorded viewport size. Note what a first-time visitor can see before scrolling.
2. Check whether the visitor can identify the service, where it is available, and what to do next. Record where any available proof appears and whether it is supported.
3. Inspect the primary contact control for visibility, labeling, and destination. Check what it opens. Test actual delivery only when authorized.
4. Recommend the smallest change that fixes the highest-impact issue. For a future brief, specify the order of the heading, coverage, proof if available, and contact action.

## Decision rules

Prioritize a broken or misleading contact action before layout refinements. If proof is unavailable, request it and use confirmed details in the interim. Keep the post’s conversion rates attributed to the author. A lead review can produce findings and a brief using public or authorized material. Apply changes within the project’s authorized scope.

## Expected output

An annotated finding or short review with the viewport, evidence, prioritized recommendations, and the intended action.

## Verification

Recheck the first screen at the same viewport and a second common mobile width. Verify that content remains readable and the contact control opens the intended destination.

## Example

A 390 px view shows a banner and a call button, but the link points to an incorrect number. Make the destination the first fix and check the service and area message next.
