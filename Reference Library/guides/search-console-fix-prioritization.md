# Prioritize a page fix with Search Console

**Topics** · seo, search-console, content

## When to use it

Use when an existing site has Search Console data and the lead needs a reasoned choice among page improvements. Apply the guide to the current brief and use the evidence and access available for that task.

## Inputs

An authorized query-and-page export with a date range, impressions, clicks, and position, plus the relevant landing pages and confirmed business priorities.

## Steps

1. Group queries by landing page and intent. Filter for relevant services and areas, then inspect a consistent date range with enough observations to interpret.
2. Read the page alongside the relevant search results. Mark each opportunity as an unanswered question, a possible title or snippet mismatch, or a landing page mismatch.
3. Pick one opportunity based on relevance, supporting evidence, and effort. Write down the intended change and expected signal before implementing it in a future authorized project.
4. Record the page, query group, date, and baseline. Recheck an equivalent window once the revised page is reflected in search, and note other changes that may affect the comparison.

## Decision rules

Low clicks alone leave several explanations open, including position, intent, and result layout. Without Search Console data, deliver a manual page review and request an export. Keep ranking and traffic numbers from the post attributed to the author. A lead review can produce findings and a brief using public or authorized material. Apply changes within the project’s authorized scope.

## Expected output

A prioritized backlog entry with its evidence, diagnosis, proposed edit, and measurement plan.

## Verification

Confirm the query is tied to the correct page and that the proposed change addresses the documented diagnosis. Compare impressions, clicks, and position together.

## Example

A repair page gets impressions for a same-day service query. Check whether availability is true and whether the page answers it. If the answer is missing and the business confirms it, propose adding the answer before rewriting the title.
