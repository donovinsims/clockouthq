# Capture a local SEO baseline before recommending changes

**Topics** · local-seo, google-business-profile, measurement

## When to use it

Use when a lead wants local SEO or GBP improvements and you need to distinguish observed conditions from later changes. Apply the guide to the current brief and use the evidence and access available for that task.

## Inputs

One location or service area, its profile and website URLs, the services that matter to the lead, and any authorized visibility or inquiry data.

## Steps

1. Record the date, location, verified services, profile fields visible to you, and current website contact path.
2. Pick a few searches tied to the lead’s actual services. Record search terms, device or tool, location or grid points, and observation time so the checks can be repeated.
3. Record available calls, forms, and other relevant inquiries for a clearly dated window. Write down the source and definition of each metric. Keep profile interactions and confirmed inquiries separate.
4. List proposed changes with an owner and date. After any authorized change, repeat the visibility checks with the same settings and compare equal-length inquiry windows.

## Decision rules

With public evidence only, deliver a limited baseline and request the missing metrics. Report seasonality, promotions, tracking changes, and other plausible explanations alongside changes in outcomes. Treat the post’s timelines and lead estimates as author observations. A lead review can produce findings and a brief using public or authorized material. Apply changes within the project’s authorized scope.

## Expected output

A dated baseline, measurement settings, and a change log suitable for a later comparison.

## Verification

Confirm the comparison uses the same terms, locations, metric definitions, and comparable windows. Label any configuration difference or data gap.

## Example

A landscaper has a visible profile but shares no analytics. Save the observed profile fields and search setup, mark inquiry counts as unknown, and request a dated export.
